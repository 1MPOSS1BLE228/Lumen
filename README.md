# Lumen — вся RGB-подсветка компьютера в одной программе

Красивое приложение для Windows 10/11: плата, видеокарта, оперативная память, вентиляторы, водянка, клавиатура и мышь —
из одного окна, без SignalRGB, iCUE и других программ. Движок подсветки встроен, ничего дополнительно ставить не нужно.

*English: Lumen is a free Windows app that controls all your PC RGB lighting from one place — themes, effects,
wallpapers and desktop widgets that match your lighting, a phone remote and more. The UI is available in
English, Ukrainian, German, Spanish and Russian.*

## Что умеет

- **Темы и эффекты.** 19 готовых тем и свои, 15 эффектов: волна, дыхание, огонь, комета, реакция на музыку,
  цвет экрана (как Ambilight), цвет по температуре видеокарты. Кнопка «Удиви меня» — случайная красивая тема.
- **Все производители.** Встроенный движок OpenRGB + «Динамическая подсветка» Windows 11. Подсветка оперативной
  памяти включается одной кнопкой (драйвер PawnIO ставится сам).
- **Windows под цвет подсветки.** Акцентный цвет панели задач и окон, обои: живые волны, абстракции или
  красивые фото в цветах темы из каталога Wallhaven, слайд-шоу.
- **Виджеты на рабочем столе.** Часы, погода с прогнозом, загрузка процессора, памяти, видеокарты, сеть, диск —
  прямо на обоях за значками, почти без нагрузки.
- **Цвета под музыку.** Подсветка берёт цвета с обложки трека: Spotify, Яндекс Музыка, YouTube в браузере.
- **Подсветка от уведомлений.** Discord, Telegram, WhatsApp и другие — мягкая вспышка цветом приложения.
- **Пульт на телефоне.** QR-код в настройках — управляй подсветкой с телефона в домашней Wi-Fi сети.
- **Сценарии.** Запустил игру — включилась её тема; ночью — выключилась; отошёл от компьютера — погасла.
- **Горячие клавиши** (работают и в играх): Ctrl+Alt+L — вкл/выкл, Ctrl+Alt+PageUp/PageDown — темы,
  Ctrl+Alt+= / Ctrl+Alt+- — яркость, Ctrl+Alt+R — «Удиви меня».
- **Обмен темами** с друзьями по коду, мини-гайд для новичков, отчёт о проблеме одной кнопкой.

## Если что-то не работает

1. Закрой SignalRGB, iCUE, Armoury Crate, G HUB и подобные программы — две программы не могут управлять
   одним устройством. Lumen сам предупредит, если такая программа запущена.
2. Не видно памяти — «Устройства» → «Включить подсветку памяти».
3. Вентиляторы на разъёмах платы — «Устройства» → «Настроить зоны»: сколько светодиодов и порядок цветов.
4. Не помогло — «Настройки» → «Сообщить о проблеме». Lumen соберёт архив с журналами и списком оборудования
   (без личных данных) — приложи его к [новой задаче](https://github.com/1MPOSS1BLE228/Lumen/issues/new).

## Сборка из исходников

- Быстро на своём компьютере: дважды кликни `Собрать-установщик.bat` — поставит Node.js, соберёт установщик в `dist`.
- Вручную: `npm install --no-save electron@45.0.0 electron-builder@26`, затем `npm test` и `npm run dist`.
- Выпуск: поменяй версию в `package.json`, допиши `CHANGELOG.md` и отправь в `main` —
  установщик соберёт, поставит метку `vX.Y.Z` и опубликует GitHub Actions (`.github/workflows/release.yml`).

Переводы — `src/shared/i18n/table.tsv` (колонки: русский, English, Українська, Deutsch, Español);
после правки: `python scripts/gen-i18n.py src/shared/i18n/table.tsv src/shared/i18n.js`.
