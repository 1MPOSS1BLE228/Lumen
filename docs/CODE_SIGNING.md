Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

## Что подписывается
- `Lumen.exe` — сама программа.
- `Lumen-Setup-X.Y.Z.exe` — установщик.

Сторонние компоненты (Electron, движок OpenRGB, установщик драйвера PawnIO) подписываются их авторами или не подписываются нами — мы подписываем только собственный код.

## Как собирается подписанный выпуск
Только автоматически, из этого репозитория, в GitHub Actions (`.github/workflows/release.yml`) по метке версии `vX.Y.Z`.
Каждый запрос на подпись подтверждается вручную.

## Конфиденциальность (Privacy policy)
Lumen не собирает телеметрию и ничего не отправляет разработчику сам. Программа обращается в интернет только для функций, которые включил пользователь:
- **Обновления** — `api.github.com` и `github.com` (проверка и скачивание новых версий этого репозитория).
- **Фото под тему** — `wallhaven.cc` (поиск и скачивание картинок по цвету темы).
- **Погода в виджетах** — `open-meteo.com` (город, который указал пользователь).
- **Пульт на телефоне** — локальный веб-сервер только в домашней сети, доступ по секретному ключу.

**Подсветка от уведомлений** читает из базы уведомлений Windows только то, от какого приложения пришло уведомление; текст сообщений не читается и никуда не передаётся.
**Отчёт о проблеме** сохраняется архивом на компьютере пользователя и никуда не отправляется автоматически; имя пользователя, имя компьютера, ключ пульта и город из него удаляются.
